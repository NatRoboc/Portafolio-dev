# Portafolio-dev
Página web que evidencia mi portafolio como Ingeniera de Software. Únicamente es el apartado Front-end del sitio.

## Wireframe (web)
Estructura base de la página web de mi portafolio. Wireframe realizado con Figma, siguiendo las buenas prácticas de Diseño Web y utilizando una escala real en píxeles. Actualmente no tiene una versión móvil. Fuente de texto, íconos y paleta de colores sujetos a cambios.
